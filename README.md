# EduCore
### School Management System

[![Live](https://img.shields.io/badge/▶_Live_Demo-000?style=for-the-badge&logo=vercel)](https://school-managment-system-flax.vercel.app)
[![API](https://img.shields.io/badge/⚙_Backend_API-46E3B7?style=for-the-badge&logo=render&logoColor=000)](https://school-managment-system-h7mn.onrender.com)

> A sleek, full-stack school management platform with role-based dashboards, attendance tracking, grade management, and a glassmorphism dark UI.

</div>

---

## ⚡ Tech Stack

```
Frontend   Next.js 14 · TypeScript · Tailwind CSS
Backend    FastAPI · SQLAlchemy (async) · PostgreSQL
Auth       JWT · bcrypt
Deploy     Vercel + Render
```

---

## 🎯 Key Features

| | Feature |
|---|---|
| 🔐 | JWT auth with 3 role levels (Admin / Teacher / Student) |
| 📊 | Admin dashboard with stats & activity feed |
| 🎓 | Student & Teacher CRUD management |
| ✅ | Attendance with Present / Late / Absent + CSV export |
| 📝 | Grades with auto letter-grade calculation (A+ scale) |
| 🌙 | Glassmorphism dark UI, fully responsive |

---

## 🚀 Quick Start

```bash
# Backend
cd backend && pip install -r requirements.txt
uvicorn main:app --reload

# Frontend
cd frontend && npm install && npm run dev
```
