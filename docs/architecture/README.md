# EduCore Architecture Notes

This directory documents the school-management domain and deployment assumptions used by the application.

- `school-workflow.md` — roles, responsibilities, academic hierarchy and grade-review flow.
- `../deployment/database-setup.md` — PostgreSQL production setup and environment configuration.

The repository should be treated as a real software project: implementation claims should match code and deployment configuration, and unverifiable historical activity should not be represented as repository evidence.
