# API Documentation

## Overview
This document describes the REST API endpoints exposed by the FastAPI backend.
The full interactive API documentation is auto-generated by FastAPI and available at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc:       `http://localhost:8000/redoc`

## Base URL
```
http://localhost:8000/api/v1
```

## Authentication
All protected endpoints require a Bearer JWT token in the Authorization header:
```
Authorization: Bearer <access_token>
```

## Endpoint Groups
| Prefix            | Description                        |
|-------------------|------------------------------------|
| /auth             | Login, logout, token refresh       |
| /users            | User account management (admin)    |
| /students         | Student profile management         |
| /teachers         | Teacher profile management         |
| /classes          | Class/course management            |
| /attendance       | Attendance recording and reporting |
| /grades           | Grade submission and reports       |
| /announcements    | School-wide announcements          |
